# SIGO-GN
SIGO-GN - Sistema Integral de Gestión Operativa.

Proyecto de la materia Sistemas Operativos del Instituto Politécnico Nacional, UPIICSA.

## Descripción
Proyecto desarrollado con React y Vite para la materia de Sistemas Operativos. El objetivo es crear un sistema integral de gestión operativa.

## Práctica 6 - Gestor de Operativos
Se desarrolló un módulo para administrar operativos mediante un tablero Kanban.

### Funcionalidades
- Registro de nuevos operativos.
- Consulta, edición y eliminación de operativos.
- Tablero Kanban con cinco estados: Nuevo, Listo, En ejecución, Bloqueado y Terminado.
- Movimiento de tarjetas mediante arrastrar y soltar.
- Validación de transiciones de estado desde el backend.
- Registro de fecha del último cambio de estado.
- Contador del tiempo transcurrido en cada estado.

### Tecnologías utilizadas
- React
- Vite
- Node.js
- Express
- JavaScript
- @hello-pangea/dnd
- JSON para almacenamiento de datos
